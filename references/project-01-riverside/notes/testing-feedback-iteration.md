# Testing, Feedback, and Iteration

## Tested Flow

Home → Find Doctors → Doctor Profile → Book Appointment → Confirmation → Manage Appointment

## Testing Checklist

- main CTA clarity
- doctor comparison
- slot selection
- date/time passing into booking
- appointment summary accuracy
- form validation
- confirmation reassurance
- manage appointment flow
- mobile responsiveness

## Iterations

### Iteration 1: Doctor listing clarity

Issue:
Doctor cards showed too many non-actionable slot chips.

Fix:
Simplified listing to comparison plus next available summary.

### Iteration 2: Slot selection flow

Issue:
Selected slot did not strongly continue into booking.

Fix:
Selected doctor/date/time pass into Booking.

### Iteration 3: Confirmation reassurance

Issue:
Confirmation page felt empty.

Fix:
Added booking reference, summary, copy/download, add-to-calendar, and before-visit checklist.

### Iteration 4: Mobile responsiveness

Issue:
Mobile felt like compressed desktop.

Fix:
Refined header, compact progress, card stacking, appointment selector, and form layout.

### Iteration 5: Typography and spacing

Issue:
Some UI elements were oversized or too heavy.

Fix:
Refined typography, spacing, buttons, and card hierarchy.
