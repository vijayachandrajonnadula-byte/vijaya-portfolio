# Riverside General — Hospital Appointment Booking Platform

## Project Type

UX/UI case study and working React prototype.

## Goal

Design and build a responsive hospital appointment booking prototype that helps users:

- find doctors
- compare doctor details
- review availability
- select a slot
- enter patient details
- confirm appointment
- manage appointment

## Core Flow

Home → Find Doctors → Doctor Profile → Select Slot → Book Appointment → Confirmation → Manage Appointment
