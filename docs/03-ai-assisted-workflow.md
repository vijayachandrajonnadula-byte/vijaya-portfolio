# AI-Assisted Product Workflow

## Principle

AI accelerates the workflow, but does not replace UX judgement.

Vijay remains responsible for:
- problem framing
- product decisions
- UX critique
- page responsibility
- responsive QA
- testing and validation
- final acceptance

## Workflow Phases

### 1. Research Framing

Tools:
- ChatGPT
- Claude
- Perplexity

Use:
- explore assumptions
- structure product questions
- compare product patterns
- generate research angles

### 2. Journey Mapping

Tools:
- Miro
- FigJam

Use:
- map user journeys
- define screen relationships
- clarify decision points
- structure information architecture

### 3. UI Exploration

Tools:
- Figma
- Figma AI
- Claude Design

Use:
- explore layout directions
- define UI hierarchy
- create visual references
- test component patterns

### 4. Prototype Build

Tools:
- Claude
- Roo Code
- Cline
- Codex
- React
- TypeScript

Use:
- convert scoped UX decisions into working screens
- build routes and components
- refine responsive layouts
- fix implementation issues
- create PR-ready changes

### 5. Review and QA

Tools:
- GitHub PRs
- Storybook
- Maze
- Manual UX review

Use:
- test flows
- review component states
- check accessibility
- validate responsive behaviour
- document iteration

### 6. Preview and Handoff

Tools:
- GitHub
- preview environments
- shareable prototype links
- Vercel for portfolio demos

Use:
- let recruiters/stakeholders open and test prototypes
- document limitations
- provide handoff notes
