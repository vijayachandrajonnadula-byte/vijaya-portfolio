# Case Study Template

Each case study should include:

1. Hero
2. Project snapshot
3. What this case study demonstrates
4. Overview
5. Problem
6. Goal
7. Research insights
8. User journey
9. Information architecture
10. Key UX decisions
11. Design system
12. AI-assisted workflow
13. Technical implementation
14. Repository and PR workflow
15. Testing and usability review
16. Feedback and iteration log
17. Responsive QA
18. Final prototype screens
19. Accessibility
20. Technical stack
21. Limitations
22. Final validation
23. Reflection
24. CTA

## Required Screenshot Types

- hero screenshot
- desktop final screens
- mobile final screens
- wireframe/process screenshots
- UI/design screenshots
- production screenshots
- optional GitHub/PR/deployment screenshots

## Case Study Must Show

- what problem was solved
- who the user is
- why the flow was designed this way
- what changed after feedback
- how AI tools supported the process
- how human judgement controlled decisions
- how the prototype was built and tested
